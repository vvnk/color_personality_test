Color Personality Test by Vivienne Kam

What your project is/does (and what it's called):
- My project is called Color Personality Test!
- It's structured as a quiz which 
- It asks the user to guess the revenue made from icecream sales at different temperatures and adds it to a plot graph

Why you made your project:
- I made this project because I watched a video on the different color types on youtube and wanted to practice my HTML, CSS, and JavaScript skills as I haven't made a website in ages
- I originally wanted to make an ikigai/mbti quiz, but decided to go with something more simple, this color quiz!

How you made your project:
- I made my project by listing out a set of questions in the planning document and assigning points for each color to them
- The way I evaluated their color result was by seeing which color category had the highest points/count
- Then I designed the original starting page (index.html)
- After I made the quiz html and the results html
- Next, I added javascript to calculate the user's results
- Everything was bare without styling, so I worked on CSS last when I had my structure and functions working properly

What you struggled with and what you learned:
- I struggled with a couple bugs throughout this project:
1. Results did not show up
- For some reason the results was only a blank div
- I had to add in console.log to debug and see what part of the code was blocking the results
- By looking at the console error I discovered that I had left an element with the id output non-existent
- I had originally deleted the id output element from quiz.html because I didn't want the users to see their count, as it was just part of the development/testing process
- To fix the problem I included the element in the html but hid it using css
2. Confetti was suddenly disabled :(
- I had copied the confetti source link from a website tutorial, but something was blocking it from running, both on the tutorial website and my color personality website? Perhaps it was a VPN or the origin code stopped working somehow?
- I searched for another tutorial website and replaced the old code with their script and it worked again!!
